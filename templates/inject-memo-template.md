## Pre-submit checklist (from the packet's "Reminder Inject Guidelines")
- [ ] Team number only — no real name anywhere (including file properties / author field)
- [ ] Every ask in the inject answered — checked against my list of asks
- [ ] Screenshots centered and labeled
- [ ] Tables labeled
- [ ] One font style and size throughout
- [ ] No jargon a non-technical reader wouldn't understand (or it's explained)
- [ ] Steps explained fully — where to go, what to click, which credentials to use (not just "log into Splunk")
- [ ] Spelling and grammar checked
- [ ] Professional memo tone
- [ ] Filename `team##_inject##.pdf`, submitted in Quotient **before the deadline**
- [ ] Written entirely by me — no AI text
